Cryptographic Avalanche Effect & Non-Repudiation Principle

When a single bit in a document is altered (even whitespace or punctuation), the SHA-256 cryptographic hash changes completely and unpredictably (known as the Avalanche Effect). Because the digital signature encrypts the original hash using the signer's private key, the decrypted hash from the public key will no longer match the recalculated document hash, causing instant mathematical rejection.
